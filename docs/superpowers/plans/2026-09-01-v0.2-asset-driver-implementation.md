# WikiSkill-Evolution V0.2 Asset Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the existing skill-only WikiSkill loop into one common gated lifecycle for `skill`, `prompt`, and `harness` assets, while recognizing `core` as a safe non-executing contract and preserving V0.1 behavior.

**Architecture:** Add a stdlib-only `wikiskill.assets` registry whose concrete drivers own proposal validation, snapshot/apply/diff/accept/rollback for one target. The existing `harness.evolve()` remains the sole orchestration loop and `gating.run_gate()` remains the sole scoring gate; the harness delegates candidate mutation to the resolved driver. Prompt overlays and harness policies live under workspace-local `assets/` roots so evolution never edits package source.

**Tech Stack:** Python 3.10+, stdlib only, Git subprocesses for local asset snapshots, pytest, pyflakes, GitHub Actions Python 3.10/3.11/3.12 matrix.

**Spec:** `docs/superpowers/specs/2026-09-01-v0.2-asset-driver-design.md`

## Global Constraints

- Preserve Raw trace immutability and fresh-sandbox grading.
- Preserve strict acceptance: `R_val > R_best`; equality is rejection.
- Preserve Wiki contents across every rejection and invalid proposal.
- Legacy proposal without `target` MUST normalize to `target="skill"`.
- Legacy workspaces without `assets/` MUST run unchanged.
- Runtime remains stdlib-only.
- V0.2 MUST NOT allow arbitrary repository Python edits, shell commands, model-weight changes, or executable core adapters.
- Prompt and harness drivers MUST reject absolute paths, `..` traversal, symlink escape, unknown keys/actions/edit operations, and wrong value types/ranges before validation rollout.
- CLI `--max-turns` remains an explicit run-time override for inference only; otherwise active harness policy is used; otherwise existing defaults are used.
- Existing Python CI matrix must be green before merge. GitHub Pages is out of scope.

---

## File Structure

- `wikiskill/assets.py` — proposal normalization, driver registry, safe path helpers, Git-backed workspace asset driver base, Skill/Prompt/Harness/Core drivers, harness-policy resolution.
- `wikiskill/gating.py` — keep scoring/run helpers; delegate legacy skill lifecycle helpers to `assets.SkillDriver` compatibility wrappers; make inference prompt workspace-aware and accept resolved inference turn limit.
- `wikiskill/harness.py` — resolve candidate driver, handle invalid proposal without gate, use driver lifecycle, resolve maintainer/proposer policy values, write target-aware history/audit.
- `wikiskill/prompts.py` — read workspace prompt overlay, append it to inference prefix only when present, render target-aware proposer instructions and gate outcome entries.
- `skills/wikiskill-proposer/SKILL.md` — document V0.2 proposal envelope and target-specific schemas.
- `tests/test_assets.py` — focused unit tests for normalization, safety, prompt/harness/core drivers and exact rollback.
- `tests/test_harness.py` — integration tests showing common Gate lifecycle and backward compatibility.
- `README.md` / `docs/index.md` — update only after behavior is proven.

```python
TARGETS = ("skill", "prompt", "harness", "core")


def normalize_proposal(proposal: dict) -> dict:
    if not isinstance(proposal, dict):
```

```python
def test_prompt_reject_rollback_restores_exact_bytes(tmp_path):

    d.prepare(ws, 1)
```

**Allowed keys and ranges:**

```python
HARNESS_POLICY_SCHEMA = {
    "inference_max_turns": (1, 500),
    "maintainer_max_turns": (1, 500),
    "proposer_max_turns": (1, 500),
    "maintainer_run_budget": (1, 100000),
```

**Harness proposal schema:**

```json
{
  "target": "harness",
  "action": "create|patch",
  "name": "policy",

  "updates": {"proposer_max_turns": 80}
}
```

`create` requires `policy`; `patch` requires `updates`. Booleans are rejected even though `bool` is a Python `int` subclass.
